# V9.5 Concise-by-Default test

Give the site to someone without explaining it. Ask them to:

1. Search a college.
2. Tell you the bottom line in under 15 seconds.
3. Compare two colleges and identify the main differences without opening the full comparison.
4. Open details only when they want evidence.
5. Build a shortlist and explain why a college ranked where it did only after opening “Why this ranking?”.

Release target: the default view should answer the immediate question without requiring the user to read methodology, source notes, or secondary metrics.
