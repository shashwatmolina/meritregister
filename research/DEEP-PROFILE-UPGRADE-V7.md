# Deep Profile Upgrade V7

## Goal
Upgrade the 30 deep profiles with the same evidence model so a comparison does not reward a college merely because one profile happened to have more prose.

## Fixed research schema
Every refreshed profile is reviewed across:

1. **Clinical scale and learning context** — teaching hospitals, current bed strength, OPD/IPD, emergency/trauma, surgery/procedures, superspecialty breadth, patient mix, what those numbers mean for an MBBS student.
2. **Academics** — curriculum/teaching model, attendance, internal assessment, bedside/skills teaching, library/reading access, current academic administration, student-reported context where attributable.
3. **Research** — formal UG entry routes, mentorship, research governance, student awards/funding, infrastructure, publication pathway and international context without inventing a USMLE score.
4. **Hostel** — eligibility/guarantee, year-wise room pattern where supported, fees, washrooms, cooling/connectivity, mess, study/recreation, currentness and block variation.
5. **Campus/student life** — sports, clubs, festivals, city access, campus character, welfare/safety and the main lifestyle trade-off.
6. **Money** — academic/hostel/mess cost and internship stipend where current evidence exists. **Service-bond terms are not used in the decision dossier or comparison weighting.**
7. **Junior culture** — kept in its dedicated evidence system rather than collapsed into a numerical score.
8. **Decision dossier** — best-fit use cases, hard facts, why they matter, trade-offs and unresolved evidence gaps.

## Evidence rules
- Prefer current official institutional documents for hard numbers.
- Do not treat advertised future capacity as current functioning capacity.
- Dated student reports are used only for lived experience and are labelled in the underlying layer.
- Missing evidence stays unresolved; it is never converted to a negative score.
- Cross-college comparison should compare like with like: same metric definition and similar time period where possible.
