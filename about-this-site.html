Project overview

About this project

This website is meant to act as a transparent, working ledger for government MBBS colleges in India. It focuses on the parts students actually need to understand quickly: college identity, location, seat count, and whether cutoff information is available for a given AIQ or category.

Scope

The project covers government MBBS colleges across India, with:

  • college name and location
  • state and city
  • management & establishment year
  • MBBS seat count
  • AIQ cutoff data where it has been added

How it is built

The site combines a nationwide directory with a partial cutoff dataset. The directory is structured around the full 456-college government MBBS list, while the cutoff layer is intentionally added only where data can be verified or clearly labelled with confidence.

What is complete

Core college metadata is present for the full set of government MBBS colleges. This is the most reliable part of the build.

How this is built & what's still missing

The college directory (name, location, management type, year established, seat intake) is sourced from National Medical Commission–derived listings for all 456 government MBBS colleges and cross-checked against the official seat count. Round-wise General-category AIQ cutoffs (39 colleges: Tamil Nadu/Puducherry + a handful of top national colleges) are sourced from MCC counselling data via one aggregator. Full category-wise (General/OBC/EWS/SC/ST) AIQ cutoffs now cover all 20 AIIMS, pieced together from two different aggregators — and those two sources disagree meaningfully for several colleges (for one AIIMS, final closing ranks reported as 1,537 vs 4,952 — a 3× gap). Cross-checking against the round-wise data suggests the lower/more-optimistic set of numbers may actually reflect an early round mislabelled as final, so every category figure here is tagged with a confidence level: moderate for numbers that could be cross-checked against a second source, low for single-source figures that couldn't be verified. Treat "low" figures as directional, not exact. Everything else — state-quota cutoffs for all 28 counselling authorities, category breakdowns beyond AIIMS, hostel details, and ragging records — is not yet populated, and nothing here is invented to fill the gaps.

On ragging specifically: there's no reliable centralized source of verified per-college incidents, and publishing unverified claims tied to a named institution risked being wrong. This build deliberately leaves that field blank rather than guess, and points to the official UGC helpline instead.

Always confirm against the official sources before making decisions: mcc.nic.in (AIQ counselling) and nmc.org.in (recognised college list). For any ragging concern, the National Anti-Ragging Helpline is 24×7 toll-free at 1800-180-5522 or helpline@antiragging.in.

Project intent

The aim is not to replace official counselling portals. It is to provide a cleaner, student-friendly starting point for understanding where a college sits in the wider government MBBS map and which data fields are already verified versus still incomplete.

What is intentionally not included

Some information is deliberately left blank instead of guessed. This includes uncertain category-wise cutoffs, hostel details, and ragging incident claims. A data gap is treated as a data gap, not a placeholder.

That is important because medical counselling decisions depend on official numbers and the latest counselling rounds. This tool is meant to make the landscape easier to understand, not to give final admissions advice.

This project should be treated as a transparent early build, not a definitive source of counselling information.

Current limitations

At this stage, the site has a fuller set of core college data, but cutoff data is only partially populated. The General AIQ data is stronger for some colleges than others, while the category-wise AIIMS data is included only where it was cross-checked or clearly labelled with confidence. State quota data is now partially populated for the Bihar and Madhya Pradesh research build, with more states still pending.
